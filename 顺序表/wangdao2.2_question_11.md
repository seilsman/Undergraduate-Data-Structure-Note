## 1、题目
## 【2011 统考真题】两个有序序列的中位数问题

设有一个长度为  
$$
L \;(L \ge 1)
$$  
的**升序序列** \( S \)，处在第  
$$
\left\lfloor \frac{L}{2} \right\rfloor
$$  
个位置的数称为序列 \( S \) 的**中位数**。

### 示例 1
若序列  
$$
S_1 = (11, 13, 15, 17, 19)
$$  
则 \( S_1 \) 的中位数是 **15**。

---

若有两个序列，其**中位数**定义为：  
> 将两个序列的所有元素合并后得到的升序序列的中位数。

### 示例 2
若  
$$
S_2 = (2, 4, 6, 8, 20)
$$  
则 \( S_1 \) 和 \( S_2 \) 的中位数是 **11**。

---

### 问题描述

现有两个**等长的升序序列** \( A \) 和 \( B \)，试设计一个在**时间复杂度和空间复杂度**两方面都尽可能高效的算法，找出序列 \( A \) 和 \( B \) 的中位数。

---

### 要求

1. 给出算法的**基本设计思想**；
2. 根据设计思想，采用 **C / C++ / Java** 语言描述算法，**关键之处给出注释**；
3. 说明所设计算法的**时间复杂度**和**空间复杂度**。


## 2、本人胡思乱想环节
最简单的方法就是将这两个顺序表合为一体，但是这样的话空间复杂度就变成了$O(n)$。所以如果要实现空间复杂度尽可能低的话就不必新建一个数组

### 1)基本设计思想：
1) 先把两个顺序表的中位数提取出来，并取最小值（时间复杂度为$O(n)$，应用了顺序表随机存储的特性）
2) 然后将"最小值"与另外一个数组的第一个元素进行比较，哪个大，另外一个数字的指针的下标就++，直到二者的指针下标相加等于L/2
### 2)算法实现：
```C
int medium(int n)//辅助函数：确定中位数位置
{
    int i = n/2;
    if(i * 2 == n)//n为偶数的情况：i=i-1
    {
        return i-1;
    }
    else//n为奇数的情况：C语言中整数除法已经完成向下取整操作，直接返回原值即可
    {
        return i;
    }
}

int MediumElem(int A[],int B[],int n)//输入变量为两个数组和两个数组的长度
 {
     int m = medium(n); 
     int a = A[m];
     int b = B[m];
     int i = 0 ;//设定一个遍历指针，用于判定是否为中位数
     int j = m;//设定的另外一个指针，遍历另一个数组
     int N = medium(2*n);
     if(a == b)//如果二者相等：代表组合后的中位数也是ta，直接返回即可
     {
        return a;
     }
     else if(a < b)
     {
        b = B[0];
        while(i + j != n-1)
        {
            if(B[i] <= A[j])
            {
                i++;
            }
            else
            {
                j++;
            }
        }
        return A[j];
     }
     else
     {
        a = A[0];
        while(i + j != N-1)
        {
            if(A[i] <= B[j])
            {
                i++;
            }
            else
            {
                j++;
            }
        }
        return B[j];
    }
 }



```

### 3)复杂度分析：
时间复杂度为$O(n)$，空间复杂度为$O(1)$

## 3、chat大人修改：


### 1)算法设计思想：
> 利用两个等长升序序列的有序性，采用分治思想求中位数。
每次分别取两个序列当前区间的中间元素进行比较，根据比较结果可以确定至少有一半元素不可能成为合并序列的中位数，从而将搜索区间缩小一半。
重复上述过程，直到每个序列中只剩一个元素，此时较小者即为合并序列的中位数。
该算法在保证正确性的同时显著降低了时间复杂度。
### 2)代码实现：
```C
//应用思想：二分查找算法
int medium(int a,int b)
{
    int m = (a+b)/2;
    if(m * 2 != a+b)
    {
        return m;
    }
    else
    {
        return m-1;
    }
}
int MediumElem(int la,int ra,int lb,int rb)//从左到右分别为a数组的最左侧下标，最右侧下标，b数组最左侧下标，最右侧下标
{
    int ma = medium(la,ra);//定义局部变量：代表A数组中间位置的下标
    int mb = medium(lb,rb);//代表B数组中间位置的下标
    if(la == ra && lb == rb )
    {
        if(A[la] < B[lb])
        return A[la];
        else
        return B[lb];
    }
    if(A[ma] < B[mb])
    {
        return MediumElem(ma+1,ra,lb,mb);
    }
    else
    {
        return MediumElem(la,ma,mb+1,rb);
    }
}
int FindMedian(int A[],int B[],int n)
{
    return MediumElem(0,n-1,0,n-1);
}
```
### 3)复杂度分析：
时间复杂度为O（1），空间复杂度为O（n）

## 4、王道解法

### 1）算法思想分析

算法的策略是从前向后扫描数组元素，标记出一个可能成为主元素的元素 `Num`，
然后重新计数，确认 `Num` 是否是主元素。

算法可分为以下两步：

**① 选取候选的主元素**

依次扫描所给数组中的每个整数，将第一个遇到的整数 `Num` 保存到变量 `c` 中，
记录 `Num` 的出现次数为 1。

若遇到的下一个整数仍等于 `Num`，则计数加 1；  
否则计数减 1。

当计数减到 0 时，将遇到的下一个整数保存到 `c` 中，
并将计数重新置为 1，开始新一轮计数。

重复上述过程，直到扫描完整个数组。

**② 判断候选主元素是否为真正的主元素**

再次扫描该数组，统计 `c` 中元素出现的次数。
若其出现次数大于 `n/2`，则 `c` 为主元素；  
否则，该序列中不存在主元素。

---

### 2）使用 C 语言描述算法如下：
```c
//运用了Boyer–Moore 投票算法
int Majority(int A[], int n)
{
    int i, c, count = 1;      // c 用来保存候选主元素，count 用来计数
    c = A[0];                 // 设 A[0] 为候选主元素

    // 查找候选主元素
    for (i = 1; i < n; i++)
    {
        if (A[i] == c)
            count++;          // 对候选主元素计数
        else if (count > 0)
            count--;          // 遇到非候选主元素，计数减 1
        else
        {
            c = A[i];         // 更换候选主元素
            count = 1;
        }
    }

    // 统计候选主元素的实际出现次数
    if (count > 0)
    {
        for (i = count = 0; i < n; i++)
            if (A[i] == c)
                count++;
    }

    // 确认是否为主元素
    if (count > n / 2)
        return c;
    else
        return -1;            // 不存在主元素
}
```
---

### （3）时间复杂度与空间复杂度分析

该算法需要对数组进行两次线性扫描，
因此时间复杂度为：$O(n)$

算法只使用了常数个辅助变量，
因此空间复杂度为：$O(1)$
