## 1、题目
## 【2011 统考真题】两个有序序列的中位数问题

设有一个长度为  
$$
L \;(L \ge 1)
$$  
的**升序序列** \( S \)，处在第  
$$
\left\lfloor \frac{L}{2} \right\rfloor
$$  
个位置的数称为序列 \( S \) 的**中位数**。

### 示例 1
若序列  
$$
S_1 = (11, 13, 15, 17, 19)
$$  
则 \( S_1 \) 的中位数是 **15**。

---

若有两个序列，其**中位数**定义为：  
> 将两个序列的所有元素合并后得到的升序序列的中位数。

### 示例 2
若  
$$
S_2 = (2, 4, 6, 8, 20)
$$  
则 \( S_1 \) 和 \( S_2 \) 的中位数是 **11**。

---

### 问题描述

现有两个**等长的升序序列** \( A \) 和 \( B \)，试设计一个在**时间复杂度和空间复杂度**两方面都尽可能高效的算法，找出序列 \( A \) 和 \( B \) 的中位数。

---

### 要求

1. 给出算法的**基本设计思想**；
2. 根据设计思想，采用 **C / C++ / Java** 语言描述算法，**关键之处给出注释**；
3. 说明所设计算法的**时间复杂度**和**空间复杂度**。


## 2、本人胡思乱想环节
最简单的方法就是将这两个顺序表合为一体，但是这样的话空间复杂度就变成了$O(n)$。所以如果要实现空间复杂度尽可能低的话就不必新建一个数组

### 1)基本设计思想：
1) 先把两个顺序表的中位数提取出来，并取最小值（时间复杂度为$O(n)$，应用了顺序表随机存储的特性）
2) 然后将"最小值"与另外一个数组的第一个元素进行比较，哪个大，另外一个数字的指针的下标就++，直到二者的指针下标相加等于L/2
### 2)算法实现：
```C
int medium(int n)//辅助函数：确定中位数位置
{
    int i = n/2;
    if(i * 2 == n)//n为偶数的情况：i=i-1
    {
        return i-1;
    }
    else//n为奇数的情况：C语言中整数除法已经完成向下取整操作，直接返回原值即可
    {
        return i;
    }
}

int MediumElem(int A[],int B[],int n)//输入变量为两个数组和两个数组的长度
 {
     int m = medium(n); 
     int a = A[m];
     int b = B[m];
     int i = 0 ;//设定一个遍历指针，用于判定是否为中位数
     int j = m;//设定的另外一个指针，遍历另一个数组
     int N = medium(2*n);
     if(a == b)//如果二者相等：代表组合后的中位数也是ta，直接返回即可
     {
        return a;
     }
     else if(a < b)
     {
        b = B[0];
        while(i + j != n-1)
        {
            if(B[i] <= A[j])
            {
                i++;
            }
            else
            {
                j++;
            }
        }
        return A[j];
     }
     else
     {
        a = A[0];
        while(i + j != N-1)
        {
            if(A[i] <= B[j])
            {
                i++;
            }
            else
            {
                j++;
            }
        }
        return B[j];
    }
 }



```

### 3)复杂度分析：
时间复杂度为$O(n)$，空间复杂度为$O(1)$

## 3、chat大人修改：


### 1) 算法设计思想：
> 利用两个等长升序序列的有序性，采用分治思想求中位数。
每次分别取两个序列当前区间的中间元素进行比较，根据比较结果可以确定至少有一半元素不可能成为合并序列的中位数，从而将搜索区间缩小一半。
重复上述过程，直到每个序列中只剩一个元素，此时较小者即为合并序列的中位数。
该算法在保证正确性的同时显著降低了时间复杂度。
### 2) 代码实现：
```C
//应用思想：二分查找算法
int medium(int a,int b)
{
    int m = (a+b)/2;
    if(m * 2 != a+b)
    {
        return m;
    }
    else
    {
        return m-1;
    }
}
int MediumElem(int la,int ra,int lb,int rb)//从左到右分别为a数组的最左侧下标，最右侧下标，b数组最左侧下标，最右侧下标
{
    int ma = medium(la,ra);//定义局部变量：代表A数组中间位置的下标
    int mb = medium(lb,rb);//代表B数组中间位置的下标
    if(la == ra && lb == rb )
    {
        if(A[la] < B[lb])
        return A[la];
        else
        return B[lb];
    }
    if(A[ma] < B[mb])
    {
        return MediumElem(ma+1,ra,lb,mb);
    }
    else
    {
        return MediumElem(la,ma,mb+1,rb);
    }
}
int FindMedian(int A[],int B[],int n)
{
    return MediumElem(0,n-1,0,n-1);
}
```
### 3)复杂度分析：
时间复杂度为O（1），空间复杂度为O（n）

## 4、王道解法

### 1）算法思想分析

### 算法的基本设计

分别求两个长度为 n 的升序序列 A、B 的中位数，设为 a 和 b。
求序列 A、B 的中位数过程如下：

1. 若 a = b，则 a 或 b 即为所求中位数，算法结束。
2. 若 a < b，则舍弃序列 A 中较小的一半，同时舍弃序列 B 中较大的一半，
   要求两次舍弃后的序列长度相等。
3. 若 a > b，则舍弃序列 A 中较大的一半，同时舍弃序列 B 中较小的一半，
   要求两次舍弃后的序列长度相等。

在保留的两个升序序列中，重复上述过程，直至两个序列中均只含一个元素为止，
较小者即为所求的中位数。


---

### 2）本题代码如下

```c
//二分查找，但是不是递归，这样空间上就不需要使用递归栈，在空间复杂度方面可以再优化
int M_Search(int A[], int B[], int n)
{
    int s1, d1, m1, s2, d2, m2;
    s1 = 0; d1 = n - 1;
    s2 = 0; d2 = n - 1;

    while (s1 != d1 || s2 != d2)
    {
        m1 = (s1 + d1) / 2;
        m2 = (s2 + d2) / 2;

        if (A[m1] == B[m2])
            return A[m1];          // 满足条件①

        if (A[m1] < B[m2])         // 满足条件②
        {
            if ((s1 + d1) % 2 == 0) // 若元素个数为奇数
            {
                s1 = m1;            // 舍弃 A 中间点以前的部分，且保留中间点
                d2 = m2;            // 舍弃 B 中间点以后的部分，且保留中间点
            }
            else                    // 元素个数为偶数
            {
                s1 = m1 + 1;        // 舍弃 A 的前半部分
                d2 = m2;            // 舍弃 B 的后半部分
            }
        }
        else                        // 满足条件③
        {
            if ((s1 + d1) % 2 == 0) // 若元素个数为奇数
            {
                d1 = m1;            // 舍弃 A 中间点以后的部分，且保留中间点
                s2 = m2;            // 舍弃 B 中间点以前的部分，且保留中间点
            }
            else                    // 元素个数为偶数
            {
                d1 = m1;            // 舍弃 A 的后半部分
                s2 = m2 + 1;        // 舍弃 B 的前半部分
            }
        }
    }

    return A[s1] < B[s2] ? A[s1] : B[s2];
}
```
---

### 3) 复杂度分析

- 时间复杂度：  
  每次循环都将问题规模缩小为原来的一半，因此时间复杂度为  
  **O(log n)**。

- 空间复杂度：  
  算法仅使用常数个辅助变量，不依赖额外数据结构，空间复杂度为  
  **O(1)**。
