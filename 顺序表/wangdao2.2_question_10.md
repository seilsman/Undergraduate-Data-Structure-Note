## 1、题目
`[2010统考真题]`设将n(n>1)个整数存放到一维数组R中。设计一个在时间和空间两方面都尽可能高效的算法。将R中保存的序列循环左移p(0<p<n)个位置，即将R中的数据由$(Xo,x1,...,Xn-1)$变换为$(Xmp+1,.,Xn-1,Xo,X1,...,Xp-1)$.要求:

1)给出算法的基本设计思想\
2)根据设计思想，采用C或C++或Java语言描述算法，关键之处给出注释\
3)说明你所设计算法的时间复杂度和空间复杂度

## 2、本人胡思乱想环节
循环左移而不是直接移动，说明直接赋值是行不通的。\
其实用后面的队列实现是非常合适的：踢出去，然后front指针指向下一个元素，rear指针指向最后加进去的内个。但是问题在于这个是一维数组R。。。算了，不指望能优化算法了，先把简单的写了再说

### 1)基本设计思想：
设计一个while循环（判断条件是移动的次数小于等于p，这个移动的次数需要先设定一个局部变量），对于数组内的元素，先将数组内的第一个元素摘出，然后将数组内的剩余元素向前移一位。最后将摘出来的元素放到最后一个位置，并且判断移动次数的局部变量+1

### 2)算法实现：
```C
void LeftRotate(int &R[], int p)//R代表读取的一维数组，p代表读取的移动数量
{
    int k = 0;
    while(k < p)
    {
        int temp = R[0];
        for(int i=1; i<n; i++) 
        {
            R[i-1]=R[i];
        } 
        R[n-1] = temp; 
        k++;
    }
}
```

### 3)复杂度分析：
空间复杂度为$O(1)$，时间复杂度为$O(n^2)$


## 3、chat大人修改：

### 1)算法设计思想：
设顺序表长度为 n，左移位数为 p。顺序表中元素的位置变化具有周期性，可将整个顺序表划分为 gcd(n, p) 个不相交的环。
每个环从不同的起始下标开始，按照 (cur + p) % n 的规则依次访问该环中的元素。
在每个环中，先用一个临时变量保存起始位置的元素，再依次将后继位置的元素前移，直到回到起始位置，将临时变量放入最后空出的位置。
所有环依次处理完成后，即可实现顺序表的循环左移，过程中不需要额外辅助数组。

### 2)代码实现：
```C
int gcd(int a, int b)
    {
    while (b != 0)
    {
        int r = a % b;
        a = b;
        b = r;
    }
    return a;
    }

bool LeftRotate(int R[], int p,int n)//R代表读取的一维数组，p代表读取的移动数量
{
    int d = gcd(n,p);
    if(p <= 0 || p>=n)
    {
        return false;
    }
    for(int i=0;i<d;i++)
    {
        int cur = i;
        int next = (i + p)% n;
        int temp = R[cur];
        while(next != i)
        {
        R[cur] = R[next];
        cur = next;
        next = (next+p) %n;
        }
        R[cur] = temp;
    }
    return true;
}
```
### 3)复杂度分析：
时间复杂度$O(n)$，空间复杂度$S(1)$

## 4、王道解法

### 1）算法思想分析
可将问题视为把数组 `ab` 转换成数组 `ba`
（`a` 代表数组的前 `p` 个元素，`b` 代表数组中余下的 `n-p` 个元素），
先将 `a` 逆置得到 `a^{-1} b`，
再将 `b` 逆置得到 `a^{-1} b^{-1}`，
最后将整个 `a^{-1} b^{-1}` 逆置得到 `(a^{-1} b^{-1})^{-1} = ba`。

设 `Reverse` 函数执行将数组逆置的操作，
对 `abcdefgh` 向左循环移动 `3`（`p = 3`）个位置的过程如下：

- `Reverse(0, p-1)` 得到 `cbadefgh`；
- `Reverse(p, n-1)` 得到 `cbahgfed`；
- `Reverse(0, n-1)` 得到 `defghabc`。

注：在 `Reverse` 中，两个参数分别表示数组中待转换元素的起始位置。

---

### 2）使用 C 语言描述算法如下：

```c
void Reverse(int R[], int from, int to)
{
    int i, temp;
    for (i = 0; i < (to - from + 1) / 2; i++)
    {
        temp = R[from + i];
        R[from + i] = R[to - i];
        R[to - i] = temp;
    }
}

void Converse(int R[], int n, int p)
{
    Reverse(R, 0, p - 1);
    Reverse(R, p, n - 1);
    Reverse(R, 0, n - 1);
}
````
---

### 3）

上述算法中三个 `Reverse` 函数的时间复杂度分别为
`O(p/2)`、`O((n-p)/2)` 和 `O(n/2)`，
故所设计的算法的时间复杂度为 `O(n)`，空间复杂度为 `O(1)`。
