## 3、chat大人给出的算法
### 1)基本设计思想：

设数组长度为 $n$。由于最小未出现的正整数一定落在区间 $[1,\,n+1]$ 内，因此只需关注数组中取值在 $[1,\,n]$ 范围内的元素。

首先对数组进行原地整理。遍历数组下标 $i=0,1,\dots,n-1$，当当前位置元素 $A[i]$ 满足 $A[i]\in[1,n]$ 且未位于其正确位置（即 $A[i]\neq i+1$，并且 $A[A[i]-1]\neq A[i]$）时，将 $A[i]$ 与其目标位置 $A[A[i]-1]$ 的元素进行交换。通过不断交换，使得每个合法的正整数尽可能被放置到与其数值对应的位置上。

完成上述整理后，再从头遍历数组，查找第一个不满足 $A[i]=i+1$ 的位置。若存在这样的下标 $i$，则 $i+1$ 即为数组中未出现的最小正整数；若所有位置均满足 $A[i]=i+1$，则说明 $1$ 到 $n$ 均已出现，最小未出现的正整数为 $n+1$。

该算法在原数组上完成操作，不需要额外的辅助存储空间。


### 2)算法实现：
```C
// 在数组 A 中查找未出现的最小正整数
int FindMin(int A[], int n)
{
    int i = 0;

    // 原地整理阶段：将合法元素放到其应在的位置
    while (i < n)
    {
        // 当 A[i] 是 [1, n] 内的正整数，且不在正确位置，
        // 并且目标位置上不是同一个值时，进行交换
        if (A[i] != i + 1 &&
            A[i] > 0 &&
            A[i] <= n &&
            A[i] != A[A[i] - 1])
        {
            int temp = A[A[i] - 1];
            A[A[i] - 1] = A[i];
            A[i] = temp;
        }
        else
        {
            // 当前元素已稳定，处理下一个位置
            i++;
        }
    }

    // 扫描阶段：寻找第一个不满足 A[j] = j + 1 的位置
    for (int j = 0; j < n; j++)
    {
        if (A[j] != j + 1)
            return j + 1;
    }

    // 若 1 到 n 均出现，则返回 n+1
    return n + 1;
}




```

### 3)复杂度分析
时间复杂度：
原地整理过程中，每个元素最多被交换一次，整体为
O(n)

空间复杂度：
仅使用常数个辅助变量，额外空间为
O(1)


## 4、王道解法

### 1）算法的基本设计思想

要求在时间上尽可能高效，因此采用**空间换时间**的方法。分配一个用于标记的数组  
$B[n]$，用来记录数组 $A$ 中是否出现了 $1 \sim n$ 的正整数。数组 $B$ 初始值全为 $0$。

由于数组 $A$ 中若包含 $n$ 个整数，则最小未出现的正整数一定在区间  
$[1,\,n+1]$ 内。当 $A$ 中包含所有 $1 \sim n$ 的整数时，返回 $n+1$；否则结果必在 $1 \sim n$ 之间。

遍历数组 $A$，当 $A[i] \in [1,n]$ 时，将 $B[A[i]-1]$ 置为 $1$；  
当 $A[i] \le 0$ 或 $A[i] > n$ 时，对结果无影响，可忽略。

完成标记后，从前向后扫描数组 $B$，找到第一个满足  
$B[i] = 0$ 的位置，则 $i+1$ 即为数组中未出现的最小正整数；  
若 $B$ 中元素全为 $1$，则返回 $n+1$。

---

### 2）算法实现（C 语言）

```c
int findMissMin(int A[], int n)
{
    int i;
    int *B;

    // 动态分配标记数组 B，并初始化为 0
    B = (int *)malloc(sizeof(int) * n);
    memset(B, 0, sizeof(int) * n);

    // 遍历数组 A，对 1~n 范围内的数进行标记
    for (i = 0; i < n; i++)
    {
        if (A[i] > 0 && A[i] <= n)
            B[A[i] - 1] = 1;
    }

    // 扫描标记数组 B，寻找第一个未出现的位置
    for (i = 0; i < n; i++)
    {
        if (B[i] == 0)
            break;
    }

    return i + 1;
}
```

### 3）时间复杂度与空间复杂度分析

- 时间复杂度：  
  遍历数组 $A$ 一次，遍历数组 $B$ 一次，每次循环中的操作均为 $O(1)$，  
  因此时间复杂度为  
  $O(n)$

- 空间复杂度：  
  额外分配了长度为 $n$ 的标记数组 $B$，  
  因此空间复杂度为  
  $O(n)$
