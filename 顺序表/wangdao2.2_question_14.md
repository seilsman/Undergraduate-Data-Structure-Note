## 1、题目
### 【2020 统考真题】 定义三元组 $(a,b,c)$（$a,b,c$ 均为整数）的距离  
$D = |a-b| + |b-c| + |c-a|$。

给定 $3$ 个非空整数集合 $S_1, S_2$ 和 $S_3$，按升序分别存储在 $3$ 个数组中，请设计一个尽可能高效的算法，计算并输出所有可能的三元组 $(a,b,c)$（$a \in S_1, b \in S_2, c \in S_3$）中的最小距离。

例如：  
$S_1 = \{-1, 0, 9\}$，  
$S_2 = \{-25, -10, 10, 11\}$，  
$S_3 = \{2, 9, 17, 30, 41\}$，  
则最小距离为 $2$，相应的三元组为 $(9, 10, 9)$。

**要求：**  
1）给出算法的基本设计思想；  
2）根据设计思想，采用 C 语言或 C++ 语言描述算法，关键之处给出注释；  
3）说明所设计算法的时间复杂度和空间复杂度。

### 1)基本设计思想：
距离公式实际上在计算上可以简化为：$2*(\max(a,b,c) = \min(a,b,c))$
所以实际上我们只需要在数组中遍历最大值和最小值的差，最后保存即可

        S[0] = A[0];

## 3、chat大人给出的算法
## 一、算法设计思想

已知三元组 $(a,b,c)$ 的距离定义为  
$D = |a-b| + |b-c| + |c-a|$。

设  
$m = \min(a,b,c)$，$M = \max(a,b,c)$，  
则有恒等式：
$D = 2(M - m)$。

因此，问题等价于：  
在 $a \in S_1,\; b \in S_2,\; c \in S_3$ 的所有组合中，  
寻找使 $\max(a,b,c) - \min(a,b,c)$ 最小的三元组。

由于三个集合已按升序存储，可采用“三指针法”：
分别用指针 $i,j,k$ 指向数组 $A,B,C$ 的当前元素。  
在每一步中计算当前三元组的距离，并更新最小距离。  
为了可能减小 $\max - \min$，每次将当前三元组中**最小值所在数组的指针向后移动一位**。  
由于每个指针只单调递增，算法在保证不遗漏最优解的同时，具有线性时间复杂度。

---

## 二、算法实现（C 语言）

```c
void MinDis(int A[], int a, int B[], int b, int C[], int c)
{
    /* 三个指针分别指向数组 A、B、C 的当前元素 */
    int i = 0, j = 0, k = 0;

    /* 用于记录当前最小距离对应的三元组 */
    int S[3];

    /* 
     * 初始化最小距离 D
     * 根据公式 D = 2 * (max(a,b,c) - min(a,b,c))
     * 初始取三数组的第一个元素构成的三元组
     */
    int D = 2 * (max(A[0], max(B[0], C[0]))
               - min(A[0], min(B[0], C[0])));

    /* 记录初始最优三元组 */
    S[0] = A[0];
    S[1] = B[0];
    S[2] = C[0];

    /*
     * 当三个指针均未越界时，循环扫描
     * 每个指针只单调向前移动，因此整体为线性时间
     */
    while (i < a && j < b && k < c)
    {
        /* 计算当前三元组中的最大值和最小值 */
        int maxv = max(A[i], max(B[j], C[k]));
        int minv = min(A[i], min(B[j], C[k]));

        /* 当前三元组的距离 */
        int cur = 2 * (maxv - minv);

        /* 若当前距离更小，则更新最小距离及对应三元组 */
        if (cur < D)
        {
            D = cur;
            S[0] = A[i];
            S[1] = B[j];
            S[2] = C[k];
        }

        /*
         * 为了可能减小 maxv - minv，
         * 将当前三元组中最小值所在数组的指针向后移动
         */
        if (A[i] == minv)
            i++;
        else if (B[j] == minv)
            j++;
        else
            k++;
    }

    /* 输出最小距离及对应的三元组 */
    printf("%d %d %d %d", D, S[0], S[1], S[2]);
}

```
### 3） 复杂度分析
在算法执行过程中，指针 $i,j,k$ 均只向前移动且最多分别移动 $a,b,c$ 次，
因此时间复杂度为
$O(a + b + c)$。

算法仅使用了常数个辅助变量，未随输入规模增长而增加额外存储空间，
故空间复杂度为
$O(1)$。


## 4、王道解法

### 分析

由  
$D = |a-b| + |b-c| + |c-a| \ge 0$  
可得如下结论：

1）当 $a=b=c$ 时，距离最小。  

2）其余情况。不失一般性，假设 $a \le b \le c$，观察下图中的数轴关系：

设  
$L_1 = |a-b|$，  
$L_2 = |b-c|$，  
$L_3 = |c-a|$，  

则  
\[
D = |a-b| + |b-c| + |c-a| = L_1 + L_2 + L_3 = 2L_3
\]

由 $D$ 的表达式可知，事实上决定 $D$ 大小的关键是 $a$ 和 $c$ 之间的距离，因此问题可以简化为：  
**每次固定 $c$，寻找一个 $a$，使得 $L_3 = |c-a|$ 最小。**

---

### 1. 算法的基本设计思想

1）使用 $D_{\min}$ 记录所有已处理的三元组的最小距离，初值为一个足够大的整数。  

2）集合 $S_1,S_2,S_3$ 分别存储在数组 $A,B,C$ 中。数组下标初值设为 $i=j=k=0$，当  
$i<|S_1|,\; j<|S_2|,\; k<|S_3|$  
时循环执行以下步骤：

- a）计算当前三元组 $(A[i],B[j],C[k])$ 的距离 $D$；
- b）若 $D < D_{\min}$，则更新 $D_{\min}$；
- c）将 $A[i],B[j],C[k]$ 中的最小值的下标加 $1$（对照分析：最小值为 $a$，最大值为 $c$，这里 $c$ 不变，尝试寻找更小的距离）。

3）输出 $D_{\min}$，算法结束。

---

### 2. 算法实现（C 语言）

```c
#define INT_MAX 0x7fffffff

int abs(int a)      /* 计算绝对值 */
{
    if (a < 0) return -a;
    else return a;
}

bool xls_min(int a, int b, int c)   /* a 是否是三个数中的最小值 */
{
    if (a <= b && a <= c) return true;
    return false;
}

int findMinofTrip(int A[], int n, int B[], int m, int C[], int p)
{
    /* D_min 用于记录三元组的最小距离，初值为 INT_MAX */
    int i = 0, j = 0, k = 0, D_min = INT_MAX, D;

    while (i < n && j < m && k < p && D_min > 0)
    {
        /* 计算当前三元组的距离 D */
        D = abs(A[i] - B[j]) + abs(B[j] - C[k]) + abs(C[k] - A[i]);

        if (D < D_min)
            D_min = D;      /* 更新 D */

        if (xls_min(A[i], B[j], C[k]))
            i++;            /* 更新 a */
        else if (xls_min(B[j], C[k], A[i]))
            j++;
        else
            k++;
    }
    return D_min;
}
```

设
$n = |S_1| + |S_2| + |S_3|$。

时间复杂度：$O(n)$

空间复杂度：$O(1)$
