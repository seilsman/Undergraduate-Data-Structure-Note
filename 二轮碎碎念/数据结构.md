# 数据结构概念入门
## 1.1数据结构三要素

> 这个主要注意一下逻辑结构，虽然不咋会考这个东西，但是稍微花一点时间就对今后的理解有很大帮助

### 1.1.1逻辑结构
**线性结构**：数据元素之间存在一对一关系\
树形结构：数据元素之间一对多关系\
网形结构：数据元素之间多对多关系\
集合：数据元素之间无直接关系（除了同属于同一个集合）
> 这里的“一对一”“一对多”指的是逻辑上的，而不是物理上的

### 1.1.2存储结构
|存储结构|特点|优点|不足|经典示例|
|--|--|--|--|--|
|顺序存储|逻辑上相邻，物理上相邻|随机存取、占存储空间小|易产生外部碎片|数组|
|链式存储|逻辑上相邻，物理上不相邻|不易产生外部碎片、删除操作容易|查找操作麻烦，需要遍历所有内容、存储指针需要额外空间|链表|
|索引存储|建立额外索引表|检索速度快|占用内存最大，增删操作麻烦（需要修改索引表）|哈希表|
|散列存储|根据元素关键字计算存储地址|检索、增加、删除速度快|效率依靠选取函数|哈希表|

## 1.2  算法与算法评价
### 1.2.1 “好”算法特点
可以正确解决问题、代码可读性强、易于维护、健壮性强（算法可以有效识别非法输入并反馈输出）、效率尽量高、占存尽量低

### 1.2.2（重点）时间复杂度和空间复杂度
时间复杂度：代码执行时间与输入规模的关系\
空间复杂度：代码执行所需空间与输入规模的关系\
衡量这两个数值通常用数量级（即$O(n)$）表示\
例：
~~~python
def find_first(arr, target):
    # 不管数组多长，只看第一个元素
    if arr[0] == target: 
    # 无论n取值多大，都只执行一次，时间复杂度O（1），没有额外的内存空间占用，空间复杂度为O（n）
        return True
    return False
~~~
数量级计算方法：\
加法法则（哪个大选哪个）：
$$O(f(n)) + O(g(n)) = O(max(f(n), g(n)))$$

示例：
$O(n) + O(n²) = O(n²)$


乘法法则（嵌套相乘）

$$O(f(n)) × O(g(n)) = O(f(n) × g(n))$$

示例：
$O(n) × O(n) = O(n²)$


> 计算时间复杂度最好的方法就是自己跟着代码“跑一遍”，然后根据输入n算出执行代码的次数，最后取最高次数即可；空间复杂度最简单，只要看有没有新创建数组，链表等，如果没有新创数组链表啥的，直接复杂度为$O(1)$

>切记不能“看到for和while就直接相乘”


### 复杂度例题：
**【2022统考真题】下列程序段的时间复杂度是（ ）**
```c
int sum=0;
for(int i=1;(i<n);i*=2)
    for(int j=0;j<i;j++)
        sum++;
```
A. $O(\log_2n)$  
B. $O(n)$  
C. $O(n\log_2n)$  
D. $O(n^2)$

>答案选B哦~如果套用乘法原则就直接选C了
