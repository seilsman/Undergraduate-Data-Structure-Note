## 1、题目
###  11

设计一个算法，使得将两个循环单链表结合，并且链接后的链表仍然保持循环形式


## 2、本人胡思乱想环节
把链表接起来，最简单的方式就是直接找到尾结点，然后修改next即可
### 代码实现
```C
void MergeLink(LinkList h1,LinkList h2)
{
    LNode *H1 = h1 -> next;
    LNode *H2 = h2 -> next;


    while(H1 -> next != h1)//找到h1链表的尾指针
    {
        H1 = H1 ->next;
    }
    while(H2 -> next != h2)//找到h1链表的尾指针
    {
        H2 = H2 ->next;
    }
    H2 -> next = h1;
    H1 -> next = h2;
}



```
### 问题
> 引入变量未引用

> 接入尾巴的时候未释放一个头结点，致使最后的链表中出现了两个头结点
## 3、chat大人给出的算法

### 一、 算法推导过程
1. **初始状态分析**\
假设我们有两个带头结点的循环单链表 h1 和 h2：\
链表 1：h1 (头) -> A1 -> A2 -> H1 (尾) -> 指回 h1\
链表 2：h2 (头) -> B1 -> B2 -> H2 (尾) -> 指回 h2

2. **目标状态**\
我们需要将它们合并成一个单一的循环链表，并且只保留一个头结点 h1：\
目标链表：h1 (头) -> A1 -> A2 -> H1 -> B1 -> B2 -> H2 -> 指回 h1

3. **步骤拆解（核心四步）**\
第一步：边界防护。在操作指针前，必须确保传入的链表 h1 和 h2 存在（不为 NULL），否则直接返回失败。\
第二步：寻找尾节点。使用 while 循环遍历，当节点的 next 指针指向自身的头结点时，说明找到了尾巴。我们分别找到 H1 和 H2。\
第三步：断尾相接与过河拆桥。\
让 H1 的 next 指向 h2 -> next（即 B1 节点），这使得链表 1 接上了链表 2 的数据部分。\
此时 h2 头结点被孤立，调用 free(h2) 释放内存，避免内存泄漏。\
第四步：首尾闭环。让链表 2 的原尾巴 H2 的 next 指向保留下来的头结点 h1，完美形成新的闭环。

### 二、 最终代码实现
下面是经过完善后的 C/C++ 代码。我调整了你原本寻找尾节点的起始位置（直接从头结点开始寻找），这样可以完美兼容“链表中只有头结点而没有数据节点”的极端情况。

```C
#include <stdlib.h> // 需要引入此头文件以使用 free() 函数

// 假设链表节点的定义如下（供参考）：
// typedef struct LNode {
//     int data;
//     struct LNode *next;
// } LNode, *LinkList;

bool MergeLink(LinkList h1, LinkList h2) {
    // 1. 边界情况防范：如果传入的头指针为空，说明链表不存在，无法合并
    if (h1 == NULL || h2 == NULL) {
        return false;
    }

    // 2. 寻找链表1的尾节点 H1
    // 从头结点开始遍历。如果链表为空（只有头结点），h1->next == h1，循环进不去，H1 留在 h1 位置，逻辑依然正确。
    LNode *H1 = h1;
    while (H1->next != h1) {
        H1 = H1->next;
    }

    // 3. 寻找链表2的尾节点 H2
    LNode *H2 = h2;
    while (H2->next != h2) {
        H2 = H2->next;
    }

    // 4. 核心连接操作（此时 H1 尾节点，H2 是尾节点）
    
    // ① 将链表1的尾部，链接到链表2的第一个真正的数据节点
    H1->next = h2->next;
    
    // ② 释放多余的链表2头结点，防止内存泄漏
    free(h2);
    
    // ③ 将链表2的尾部，链接到链表1的头结点，形成大闭环
    H2->next = h1;

    // 5. 合并成功，返回 true
    return true;
}
```

## 4、王道解法

### 算法思想
先找到两个链表的尾指针，将第一个链表的尾指针与第二个链表的头结点链接起来，再使之成为循环的。

### 本题代码如下

```c
LinkList Link(LinkList &h1, LinkList &h2) {
    // 将循环链表 h2 链接到循环链表 h1 之后，使之仍保持循环链表的形式
    LNode *p, *q;               // 分别指向两个链表的尾结点
    
    p = h1;
    while (p->next != h1) {     // 寻找 h1 的尾结点
        p = p->next;
    }
    
    q = h2;
    while (q->next != h2) {     // 寻找 h2 的尾结点
        q = q->next;
    }
    
    p->next = h2;               // 将 h2 链接到 h1 之后
    q->next = h1;               // 令 h2 的尾结点指向 h1
    
    return h1;
}
```
