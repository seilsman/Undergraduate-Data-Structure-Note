### 13. 访问频度调整的链表查找问题

设将 $n (n > 1)$ 个整数存放到不带头结点的单链表 $L$ 中，设计算法将 $L$ 中保存的序列循环右移 $k (0 < k < n)$ 个位置。例如，若 $k = 1$，则将链表 $\{0, 1, 2, 3\}$ 变为 $\{3, 0, 1, 2\}$。要求：

## 2、本人胡思乱想环节
与顺序表中的右移不同，链式表中的右移只需要将后k个结点的尾结点和链接这个k个结点的next指针改变即可（k个结点内部依然保持有序）
我们只需要遍历到 尾部指针 和 存放k个结点之前的指针 
然后将尾部指针指向原来的头指针，将前面原队列的尾部指针指向NULL就好了


### 代码实现
```C
void RotateLink(LinkList &L,int k)
{
    if(L == NULL)
    {
        return;
    }
    LNode *rear = L;
    int n = 1;
    while(rear -> next != NULL)
    {
        rear = rear -> next;
        n++;
    }   
    LNode *change = L;
    int i = 1;
    while(i < n-k)
    {
        change = change -> next;
        i++;
    }
    if(change -> next == NULL || i != n-k)
    {
        return;
    }
    LNode *head = change -> next;
    change -> next = NULL;
    rear -> next = L;
    L = head;
}


```
### 效率分析

**时间复杂度**：$O(n+k)$
**空间复杂度**：$O(1)$

### 一、 算法推导过程

**统计长度并寻尾 📏**
遍历单链表 $L$，统计结点个数 $n$，并找到原链表的最后一个结点 rear。由于单链表不带头结点，我们从第一个结点开始计数。

**闭合成环 🔗**
将原尾结点 rear 的 next 指针指向第一个结点 $L$，从而将单链表转变为循环单链表。寻找断点并重构 ✂️

**定位新尾**
循环右移 $k$ 位，意味着原序列的倒数第 $k$ 个结点将成为新序列的头结点。因此，新序列的尾结点是原序列的第 $n - k$ 个结点。

**断开连接**
从原头结点出发，向后移动 $n - k - 1$ 次找到新尾结点。

**更新头指针**
记录新尾结点的下一个结点为新的头结点 $L$，然后将新尾结点的 next 置为 NULL，重新恢复为单链表结构。

### 二、 最终代码实现


```C
void RotateLink(LinkList &L, int k) {
    if (L == NULL || k <= 0) return;

    LNode *p = L;
    int n = 1;

    // 1. 找到原尾结点，并计算长度 n
    while (p->next != NULL) {
        p = p->next;
        n++;
    }

    // 2. 将尾巴指向头，形成循环链表
    p->next = L;

    // 3. 找到新尾巴的位置
    // 旋转 k 位，意味着新尾巴在原头开始的第 n - k - 1 个位置
    LNode *newRear = L;
    for (int i = 0; i < n - k - 1; i++) {
        newRear = newRear->next;
    }

    // 4. 在新尾巴处断开，并更新头指针 L
    L = newRear->next;     // 新头是新尾的下一个
    newRear->next = NULL;  // 断开环
}
```
### 复杂度分析
时间复杂度：$O(n)$

空间复杂度：$O(1)$

13. 【解答】
### 1）算法的基本设计思想

首先，遍历链表计算表长 $n$，并找到链表的尾结点，将其与首结点相连，得到一个循环单链表。  
然后，找到新链表的尾结点，它为原链表的第 $n-k$ 个结点。令 $L$ 指向新链表尾结点的下一个结点，并将环断开，得到新链表。

---

### 2）本题代码如下

```c
LNode *Converse(LNode *L,int k){
    int n = 1;           // n 用来保存链表的长度
    LNode *p = L;        // p 为工作指针

    while(p->next != NULL){  // 计算链表的长度
        p = p->next;
        n++;
    }                        // 循环执行后，p 指向链表尾结点

    p->next = L;             // 将链表连成一个环

    for(int i = 1; i <= n - k; i++)  // 寻找链表的第 n-k 个结点
        p = p->next;

    L = p->next;             // L 指向新链表尾结点的下一个结点
    p->next = NULL;          // 将环断开

    return L;
}
```

---

### 3）复杂度分析

- 时间复杂度：  
  $$
  O(n)
  $$
  需要遍历链表求长度一次，并再次移动指针寻找第 $n-k$ 个结点。

- 空间复杂度：  
  $$
  O(1)
  $$
  只使用了常数个辅助指针变量。
