## 1、题目
###  10

两个整数序列  
$A = a_1, a_2, a_3, \cdots, a_m$ 和  
$B = b_1, b_2, b_3, \cdots, b_n$  

已经存入两个单链表中。设计一个算法，判断序列 $B$ 是否是序列 $A$ 的连续子序列。


## 2、本人胡思乱想环节
只需要判断而不需要输出，那么只需要两个指针即可
先从链表A的刚开始进行遍历直到存在B链表的第一个元素为止，随后一起进行遍历

### 代码实现
```C
bool SubSequence(LinkList A,LinkList B)
{
    LNode *pa = A -> next;
    LNode *pb = B -> next;
    if(B -> next == NULL)//B链表是空链表：空序列是所有序列的连续子序列
    {
        return true;
    }
    
    while(pa != NULL && pb != NULL)//开始比较B序列和A序列的部分元素
    {
        if(pa ->data == pb -> data)//如果序列上某个元素相等：继续推进，直到pb指针为NULL
        {
            pa = pa -> next;
            pb = pb -> next;
        }
        else if(pa -> data != pb ->data && pa -> data == B-> next -> data)//如果对应元素不相等，但是pa指针指向结点的值与B序列首项的值相等：将pb指针初始化为B序列的首项，重新进行新一轮的比较
        {
            pb = B ->next;
        }
        else//对应元素不相等，且也与B序列首项元素不相等：推进pa指针，直到pa指针指向的值与B序列首项元素相等为止。没有重置pb指针是为了避免冗余操作导致的内存浪费
        {
            pa = pa -> next;
        }
           
    }
    /*最后比较pb指针即可：
     pb指针为空：要不然就是与pa指针比较到序列尾部，代表所有的比较都结束了，B序列是A序列的连续子序列
                要不然就是本身就是空序列，空序列是所有序列的连续子序列（参考集合）
     pb序列不为空：B序列不是空序列且与A序列的比较仍未结束，那么pa指针此时一定为空，B序列一定不是A序列的连续子序列
    */
    if(pb != NULL)
    {
        return false;
    }
    else
    {
        return true;
    }
}


```
### 问题
> 逻辑仍然有漏洞：忽略了部分匹配下这个算法可能会出现“跳步”的情况

## 3、chat大人给出的算法



### 算法思想

由于序列存储在单链表中，不能随机访问，因此需要通过**顺序扫描**实现匹配。

基本思路如下：

1. 设指针 `pa` 在链表 A 中逐个扫描，作为可能的匹配起点。
2. 当发现 `A` 当前结点值与 `B` 首结点值相等时：
   - 使用两个临时指针 `p` 和 `q` 同时向后比较。
3. 若 `B` 中所有结点都能匹配成功，则说明 **B 是 A 的连续子序列**。
4. 若中途出现不匹配，则继续从 `A` 的下一个结点重新尝试匹配。
5. 若 `A` 遍历结束仍未完全匹配 `B`，则说明 **B 不是 A 的连续子序列**。

---

### C语言实现（带详细注释）

```c
bool IsSubSequence(LinkList A, LinkList B)
{
    LNode *pa = A->next;   // pa 用于扫描链表 A
    LNode *pb = B->next;   // pb 指向链表 B 的首元结点

    // 若 B 为空序列，则必然是 A 的子序列
    if(pb == NULL)
        return true;

    // 在 A 中寻找可能的起始匹配位置
    while(pa != NULL)
    {
        // 如果当前元素相等，尝试进行连续匹配
        if(pa->data == pb->data)
        {
            LNode *p = pa;   // p 用于扫描 A 的后续部分
            LNode *q = pb;   // q 用于扫描 B

            // 同时向后比较两个链表
            while(p != NULL && q != NULL && p->data == q->data)
            {
                p = p->next;
                q = q->next;
            }

            // 若 q 已遍历结束，说明 B 全部匹配成功
            if(q == NULL)
                return true;
        }

        // A 指针继续后移，寻找新的匹配起点
        pa = pa->next;
    }

    // A 遍历结束仍未匹配成功
    return false;
}
```

---

### 时间复杂度

设：

* A 的长度为 $m$
* B 的长度为 $n$

最坏情况下：

$$
T(m,n) = O(mn)
$$

例如：

```
A = 1 1 1 1 1 1
B = 1 1 1 2
```

每个位置都可能触发一次完整匹配。

---

### 空间复杂度

算法只使用了若干辅助指针：

$$
S(n) = O(1)
$$

---

### 算法特点

1. **顺序扫描链表**
2. **模拟字符串匹配过程**
3. **无需额外存储空间**
4. 适用于 **单链表结构**

---

### 一句话方法总结

> 通过在链表 A 中逐个寻找与 B 首元素相同的起点，并进行顺序匹配，判断 B 是否能在 A 中连续出现。



## 4、王道解法
### 算法思想

因为两个整数序列已存入两个链表中，操作从两个链表的第一个结点开始。  
若对应数据相等，则后移指针；若对应数据不等，则 A 链表从上次开始比较结点的后继开始，B 链表仍从第一个结点开始比较，直到 B 链表到尾表示匹配成功。A 链表到尾而 B 链表未到尾表示失败。  
操作中应记住 A 链表每次的开始结点，以便下次匹配时好从其后继开始。

---

### 代码实现

```c
int Pattern(LinkList A, LinkList B) {
    LNode *p = A;        // p 为 A 链表的工作指针（本题假定 A 和 B 均无头结点）
    LNode *pre = p;      // pre 记住每次开始比较时 A 链表的开始结点
    LNode *q = B;        // q 为 B 链表的工作指针

    while (p && q) {
        if (p->data == q->data) {  // 结点值相同
            p = p->next;
            q = q->next;
        } else {
            pre = pre->next;
            p = pre;   // A 链表新的开始比较结点
            q = B;     // q 从 B 链表第一个结点重新开始
        }
    }

    if (q == NULL)      // B 已经比较结束
        return 1;       // 说明 B 是 A 的子序列
    else
        return 0;       // B 不是 A 的子序列
}
```
