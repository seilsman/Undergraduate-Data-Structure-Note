### 一、算法的基本设计思想

单链表若存在环，则链表中的某些结点会被**重复访问**。为了检测这一结构特征，可以采用**快慢指针法（Floyd 判环算法）**：

* 设置两个指针：

  * **slow 指针**：每次向后移动 1 个结点；
  * **fast 指针**：每次向后移动 2 个结点。
* 两个指针同时从链表头结点开始移动。

根据链表结构不同，会出现两种情况：

1. **若链表无环**
   快指针会先到达链表尾部，使得 `fast == NULL` 或 `fast->next == NULL`，算法结束，说明链表无环。

2. **若链表有环**
   在环结构中，快指针移动速度快于慢指针，因此会在环内不断追赶慢指针，最终两指针必然在某个结点**相遇**。一旦出现 `slow == fast`，即可判定链表存在环。

该方法利用了环形结构中指针运动的**相对速度差异**来检测循环结构，无需额外存储空间。

---

### 二、算法实现（C语言）

```c
#include <stdbool.h>

typedef struct LNode
{
    int data;
    struct LNode *next;
}LNode, *LinkList;

/*
判断单链表是否存在环
若存在环返回 true，否则返回 false
*/
bool HasCycle(LinkList L)
{
    // 若链表为空或只有一个结点，则一定无环
    if(L == NULL || L->next == NULL)
        return false;

    LNode *slow = L;   // 慢指针，每次移动一步
    LNode *fast = L;   // 快指针，每次移动两步

    while(fast != NULL && fast->next != NULL)
    {
        slow = slow->next;          // 慢指针走一步
        fast = fast->next->next;    // 快指针走两步

        // 若两指针相遇，说明链表存在环
        if(slow == fast)
            return true;
    }

    // 快指针到达NULL，说明链表无环
    return false;
}
```

#### 关键实现要点

1. **循环条件**

```c
fast != NULL && fast->next != NULL
```

原因：

* `fast` 每次移动两步，需要保证：

  * 当前结点存在
  * 下一个结点也存在

否则访问 `fast->next->next` 会发生非法访问。

2. **相遇判定**

```c
if(slow == fast)
```

指针指向同一结点时即可判定存在环。

### 三、复杂度分析

* 在无环情况下，快指针最多遍历整个链表一次。
* 在有环情况下，两指针在进入环后最多经过一圈即可相遇。

因此算法的时间复杂度为

[
O(n)
]

]

## 4、王道解法

15.【解答】

### 1）算法的基本设计思想

设置快慢两个指针分别为 `fast` 和 `slow`，最初都指向链表头 `head`。

- `slow` 每次走一步，即  
  $$slow = slow \rightarrow next$$

- `fast` 每次走两步，即  
  $$fast = fast \rightarrow next \rightarrow next$$

由于 `fast` 的移动速度快于 `slow`：

- 若链表 **无环**，则 `fast` 会先到达链表尾部；
- 若链表 **有环**，则 `fast` 一定会进入环，而 `slow` 随后也会进入环。

当两个指针都进入环后，继续移动一段时间必然会 **相遇**。

如下图所示，当 `slow` 刚进入环时，`fast` 早已进入环。由于 `fast` 每次比 `slow` 多走一步，因此 `fast` 与 `slow` 之间的距离不断缩小，最终必然相遇。

设：

- 头结点到 **环入口结点** 的距离为  
  $$a$$

- 从 **环入口结点** 沿环方向到 **相遇结点** 的距离为  
  $$x$$

- **环长度** 为  
  $$r$$

- 相遇时 `fast` 比 `slow` 多绕环  
  $$ n $$

则有：

$$
2(a+x) = a + n r + x
$$

整理可得：

$$
a = n r - x
$$

这说明：

**头结点到环入口的距离，等于若干个环长度减去相遇点到入口的距离。**

因此可以设置两个指针：

- 一个指针 `p1` 从 **head** 出发；
- 一个指针 `p2` 从 **相遇点** 出发；

两个指针 **每次都走一步**，最终相遇的结点即为 **环的入口结点**。

---

### 2）本题代码如下

```c
LNode *FindLoopStart(LNode *head)
{
    LNode *fast = head, *slow = head;  // 设置快慢两个指针

    while(fast != NULL && fast->next != NULL)
    {
        slow = slow->next;        // 每次走一步
        fast = fast->next->next;  // 每次走两步

        if(slow == fast)          // 相遇
            break;
    }

    if(fast == NULL || fast->next == NULL)
        return NULL;              // 没有环，返回NULL

    LNode *p1 = head, *p2 = slow; // 分别指向开始点和相遇点

    while(p1 != p2)
    {
        p1 = p1->next;
        p2 = p2->next;
    }

    return p1;                    // 返回入口点
}
````

---

### 3）复杂度分析

当 `fast` 与 `slow` 相遇时，`slow` 尚未遍历完整个链表。

因此：

* **时间复杂度**

$$
O(n)
$$

* **空间复杂度**

$$
O(1)
$$
