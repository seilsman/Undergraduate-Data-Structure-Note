### 19.【2015 统考真题】

用单链表保存 $m$ 个整数，结点的结构为 `[data][link]`，且 $|data| \le n$（$n$ 为正整数）。  
现要求设计一个**时间复杂度尽可能高效的算法**，对于链表中 `data` 的**绝对值相等的结点**，仅保留**第一次出现的结点**，而删除其余绝对值相等的结点。

例如，若给定的单链表 `head` 如下：

```

head
↓
[21] → [-15] → [15] → [-7] → [15] → ^

```

则删除结点后的 `head` 为：

```

head
↓
[21] → [-15] → [-7] → ^

```

由于题目已经给出了绝对值小于n这个条件，所以我们可以“用空间换时间”，通过创建辅助数组达到一遍遍历解决问题的情况


### 代码实现
```C
typedef struct LNode
{
    int data;
    struct LNode *link;
}LNode,*LinkList;

int Abs(int data)
{
    
    if(data < 0)
    {
        return -data;
    }
    else
    {
        return data;
    }
}

void DeleteSame(LinkList L,int n)
{
    int *arr = (int*)malloc((n+1) *sizeof(int));
    for(int i=0; i < n+1 ;i++)
    {
        arr[i] = 0;
    }
    LNode *pre = L;
    if(L->link == NULL)
    {
        free(arr);
        return;
    }
    while(pre -> link != NULL)
    {
        LNode *cur = pre -> link;
        int x = Abs(cur -> data);
        if(arr[x] == 0)
        {
            arr[x]++;
            pre = pre -> link;
        }
        else
        {
            pre -> link = cur -> link;
            free(cur);
        }
    }
}
```
### 效率分析

**时间复杂度**：$O(n)$
**空间复杂度**：$O(n)$

### 一、算法的基本设计思想

题目给出条件：

$$
|data| \le n
$$

因此，结点 `data` 的绝对值只可能在区间

$$
[0,n]
$$

之间。

据此可以建立一个 **辅助数组 `flag[0..n]`**，用于记录某个绝对值是否已经出现过。

算法过程如下：

1. 申请一个长度为 $n+1$ 的数组 `flag`，并初始化为 `0`。
2. 从链表头结点开始遍历链表。
3. 对当前结点 `cur`：

   * 计算其数据的绝对值

     $$
     x = |cur->data|
     $$
4. 判断 `flag[x]`：

   * 若 `flag[x] == 0`

     * 说明该绝对值**第一次出现**
     * 保留该结点，并令 `flag[x] = 1`
   * 若 `flag[x] == 1`

     * 说明该绝对值**已经出现过**
     * 删除该结点
5. 遍历直到链表结束。

该算法只需 **一次遍历链表** 即可完成删除操作。

---

### 二、单链表结点的数据类型定义（C语言）

```c
typedef struct LNode
{
    int data;           // 数据域
    struct LNode *link; // 指针域
}LNode,*LinkList;
```

### 三、算法描述（C语言实现）

```c
#include <stdlib.h>

void DeleteSame(LinkList L,int n)
{
    // 建立辅助数组，用于记录某绝对值是否已经出现
    int *flag = (int*)calloc(n+1,sizeof(int));

    LNode *pre = L;           // pre始终指向当前结点的前驱

    while(pre->link != NULL)
    {
        LNode *cur = pre->link;   // 当前处理结点
        int x = abs(cur->data);   // 求data的绝对值

        if(flag[x] == 0)
        {
            // 第一次出现，保留结点
            flag[x] = 1;
            pre = pre->link;
        }
        else
        {
            // 已经出现过，需要删除该结点
            pre->link = cur->link;
            free(cur);
        }
    }

    free(flag); // 释放辅助数组空间
}
```

#### 关键说明

* `pre` 指针始终指向 **当前结点的前驱结点**。
* 删除结点时 **不移动 `pre`**，否则会跳过后续结点。
* `flag[x]` 用于记录绝对值 `x` 是否已经出现。

---

### 四、时间复杂度与空间复杂度分析

设链表中结点个数为 $m$。

#### 时间复杂度

算法只对链表进行 **一次遍历**，且每个结点的操作为常数时间：

$$
T(m) = O(m)
$$

这是该问题能够达到的 **最优时间复杂度**。

---

#### 空间复杂度

需要额外使用一个长度为 $n+1$ 的辅助数组：

$$
S(n) = O(n)
$$

---

### 方法论总结

该题的核心思想是：

> **当数据值域有限时，可以利用辅助数组进行状态标记，将查重问题从 $O(m^2)$ 优化为 $O(m)$。**

这种思想在 **链表去重、桶排序、计数排序等问题**中广泛应用。📊





## 4、王道解法

### 19.【解答】

#### 1）算法的基本设计思想

- 算法的核心思想是**用空间换时间**。使用辅助数组记录链表中已出现的数值，从而只需对链表进行一趟扫描。
- 因为 $|data| \le n$，故辅助数组 $q$ 的大小为 $n+1$，各元素的初值均为 $0$。
- 依次扫描链表中的各结点，同时检查 $q[|data|]$ 的值：
  - 若为 $0$，则保留该结点，并令 $q[|data|] = 1$；
  - 否则说明该绝对值已经出现过，则将该结点从链表中删除。

---

#### 2）使用 C 语言描述的单链表结点的数据类型定义

```c
typedef struct node {
    int data;
    struct node *link;
}NODE;

typedef NODE *PNODE;
````

---

#### 3）算法实现如下

```c
void func(PNODE h,int n){
    PNODE p=h,r;
    int *q,m;

    q=(int *)malloc(sizeof(int)*(n+1));   // 申请 n+1 个位置的辅助空间

    for(int i=0;i<n+1;i++)                // 数组元素初始化为 0
        *(q+i)=0;

    while(p->link!=NULL){
        m = p->link->data>0 ? p->link->data : -p->link->data;

        if(*(q+m)==0){                    // 判断该结点的 data 是否已出现过
            *(q+m)=1;                     // 第一次出现
            p=p->link;                    // 保留
        }
        else{                             // 重复出现
            r=p->link;                    // 删除
            p->link=r->link;
            free(r);
        }
    }

    free(q);
}
```

---

#### 4）复杂度分析

* **时间复杂度**

$$
O(m)
$$

其中 $m$ 为链表中结点个数，仅需对链表进行一次遍历。

* **空间复杂度**

$$
O(n)
$$

因为需要一个大小为 $n+1$ 的辅助数组。
