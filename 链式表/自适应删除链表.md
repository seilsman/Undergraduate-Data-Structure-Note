## 1️⃣ Self-Adjusting List 的思想

**核心思想**：

1. **频繁访问的元素靠前**：每次访问一个元素时，其访问频度 `freq` 增加 1，然后根据新的 `freq` 值将结点移动到合适位置。
2. **按访问频度递减排序**：链表中的结点按 `freq` 从大到小排列。访问次数多的结点越靠前。
3. **相同访问频度按最近访问靠前**：如果多个结点 `freq` 相同，则最近访问的结点排在同类结点的前面。
4. **头结点不存数据**：链表带头结点，便于插入和移动结点操作。

**优点**：

* 高频访问元素快速找到。
* 不需要全表扫描排序，只调整部分链表即可。
* 对局部访问有很好的适应性。

## 2️⃣ 实现思路

**Locate(L, x) 运算步骤**：

1. **查找结点**：从 `L->next` 开始遍历，找到 `data == x` 的结点 `p`。
2. **更新访问频度**：`p->freq += 1`
3. **断开结点**：将 `p` 从原位置移除。
4. **重新插入**：

   * 从当前结点的`pre`结点开始遍历链表，找到第一个 `freq` **大于 `p->freq`** 的位置 `q`。
   * 将 `p` 插入到 `q` 后面。
5. **返回结点**：返回找到的结点地址（或 NULL 如果未找到）。

## 3️⃣ C语言实现

```c
LNode *Locate(LinkList L,int x)
{
    LNode *cur = L->next;

    while(cur != NULL && cur->data != x)
        cur = cur->next;

    if(cur == NULL)
        return NULL;

    cur->freq++;

    //摘链（易错点，注意理解）
    cur->prev->next = cur->next;
    if(cur->next != NULL)
        cur->next->prev = cur->prev;

    //向前寻找插入位置
    LNode *pre = cur->prev;

    while(pre != L && pre->freq <= cur->freq)
        pre = pre->prev;

    //插入
    cur->next = pre->next;
    cur->prev = pre;

    if(pre->next != NULL)
        pre->next->prev = cur;

    pre->next = cur;

    return cur;
}
//断链的边界条件，和前移寻找插入位置的边界条件判断要清楚！
//（前者在某些条件下可能会引起memory leak，后者会导致在时间效率上大打折扣）

```

## 4️⃣ 方法总结（一句话）

> 在访问频度递减的链表中，结点访问后频度只增加 1，因此只需从当前位置向前扫描寻找插入点，而无需从表头重新查找。
