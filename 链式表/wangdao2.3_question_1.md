## 1、题目

在带头结点的单链表 $L$ 中，删除所有值为 $x$ 的结点，并释放其空间。  

假设值为 $x$ 的结点不唯一，试编写算法实现上述操作。




## 2、本人胡思乱想环节

肯定要进行整个单链表的遍历，既然结点不唯一的话，那么我们进行遍历循环的退出条件就得是`d -> next == NULL`
温习一下删除操作：这里接一下那里接一下，然后`free()`

### 代码实现
```C
void DeleteElem(LNode *L,int x)
{
    LNode I = L;

    while(L -> next != NULL && I -> next != NULL)//外循环的进入条件要写好！
    { 
        while(I -> next -> data == x)
        {
            LNode N = I -> next;
            I -> next = N -> next;
            free(N);
        }
        I = I -> next;
    }
}


```
### 单链表删除算法代码问题分析

很好，这段代码可以作为一个“典型错误样本”进行系统分析。  
下面从**类型设计、循环条件、空指针安全、控制流逻辑、本质不变量**五个层面逐条拆解。

---

#### 一、类型层面的错误 ❗（根本性问题）

```c
LNode I = L;
```

函数参数为：

```c
void DeleteElem(LNode *L, int x)
```

如果链表定义为常规形式：

```c
typedef struct LNode {
    int data;
    struct LNode *next;
} LNode;
```

那么：

- `L` 的类型是 `LNode*`
- `I` 的类型是 `LNode`
- 代码却写成 `LNode I = L;`

这是**结构体接收指针类型**，类型不匹配。

 正确写法应为：

```c
LNode *I = L;
```

除非使用了：

```c
typedef struct LNode* LNode;
```

否则当前代码在类型层面就不成立。

---

#### 二、外层循环条件逻辑错误 ❗

```c
while(L -> next != NULL && I -> next != NULL)
```

问题有两个：

##### 1️⃣ `L->next != NULL` 是多余的

遍历过程中真正移动的是 `I`，不是 `L`。

- 如果 `L->next == NULL`，说明链表为空
- 这种情况完全可以在函数开始单独判断
- 没必要把它放入循环条件

##### 2️⃣ 语义混乱

`L` 是头指针  
`I` 是遍历指针  

遍历条件应只依赖当前工作指针 `I`。

正确范式：

```c
while(I->next != NULL)
```

将不同语义的指针混入同一判断条件，会导致控制流设计不清晰。

---

#### 三、内层 while 存在严重空指针风险 ❗（最致命）

```c
while(I -> next -> data == x)
```

这里没有先判断：

```c
I->next != NULL
```

考虑极端情况：

```
头 -> 3 -> 3
```

删除后：

```
头 -> NULL
```

此时：

```c
I->next == NULL
```

但下一轮仍会判断：

```c
I->next->data
```

直接发生段错误。

---

#### 四、删除后指针推进逻辑错误 ⚠️

当前结构：

```c
while(I->next != NULL)
{
    while(删除条件)
    {
        删除操作
    }
    I = I->next;
}
```

问题在于：

当删除完后，如果：

```c
I->next == NULL
```

仍然执行：

```c
I = I->next;
```

则：

```c
I = NULL;
```

下一轮判断：

```c
I->next != NULL
```

会直接崩溃。

---

#### 五、控制流设计不稳健 🧠

当前使用“双重 while”结构。

这种结构的问题：

- 删除后逻辑跳转复杂
- 容易遗漏空指针判断
- 指针推进容易出错

更稳健的结构应为：

```c
while(I->next != NULL)
{
    if(I->next->data == x)
        删除
    else
        I = I->next;
}
```

该结构具有：

- 单一循环
- 线性控制流
- 更容易验证正确性
- 更低空指针风险

---

#### 六、本质问题（不变量分析）

该代码暴露出一个核心问题：

> 在删除操作中没有建立“前驱指针保持稳定”的严格不变量。

正确的单链表删除范式中有一个关键不变量：

```
I 始终指向当前待检查结点的前驱结点
```

如果这个不变量被破坏，就容易发生：

- 空指针错误
- 跳过结点
- 非法访问

建立并维护不变量，是链表算法正确性的核心。


## 3、chat大人给出的算法

### 算法实现（C 语言）

```c
// 删除带头结点单链表中所有值为 x 的结点
// 参数 L：指向头结点指针的指针
// 参数 x：待删除的元素值

void DeleteElem(LNode *L, int x)
{
    // I 始终指向待检查结点的前驱结点
    LNode I = *L;

    // 当 I 的后继结点存在时继续遍历
    while (I->next != NULL)
    {
        // 如果后继结点的数据域等于 x，则删除该结点
        if (I->next->data == x)
        {
            // 保存待删除结点
            LNode N = I->next;

            // 修改前驱结点指针，跳过待删除结点
            I->next = N->next;

            // 释放被删除结点的空间
            free(N);
        }
        else
        {
            // 若当前结点不删除，则前驱指针后移
            I = I->next;
        }
    }
}
```


## 4、王道解法

### 解法 1

**思路说明：**

用 `p` 从头至尾扫描单链表，`pre` 指向 `p` 结点的前驱。  
若 `p` 所指结点的值为 `x`，则删除该结点；否则 `pre` 和 `p` 同步后移。

---

```c
void Del_X_1(LinkList &L, ElemType x)
{
    LNode *p = L->next, *pre = L, *q;   // 置 p 和 pre 的初始值

    while (p != NULL)
    {
        if (p->data == x)
        {
            q = p;              // q 指向被删除结点
            p = p->next;
            pre->next = p;      // 将 *q 结点从链表中断开
            free(q);            // 释放 *q 结点的空间
        }
        else
        {
            pre = p;            // 否则，pre 和 p 同步后移
            p = p->next;
        }
    }
}
```

---

**说明：**

本算法是在无序单链表中删除满足某种条件的所有结点，这里的条件是结点值为 `x`。  

若要删除值不在区间 `[min, max]` 内的所有结点，只需将判断语句：

```c
if (p->data == x)
```

修改为：

```c
if (p->data >= min && p->data <= max)
```

即可。

---

### 解法 2

**思路说明：**

采用尾插法重新构造链表。  
用 `p` 指针扫描 `L` 的所有结点：

- 若结点值不为 `x`，则将其链接到新链表尾部；
- 若结点值为 `x`，则释放该结点。

---

```c
void Del_X_2(LinkList &L, ElemType x)
{
    LNode *p = L->next, *r = L, *q;   // r 指向尾结点，其初值为头结点

    while (p != NULL)
    {
        if (p->data != x)     // p 结点值不为 x 时将其链接到尾部
        {
            r->next = p;
            r = p;
            p = p->next;      // 继续扫描
        }
        else                  // p 结点值为 x 时将其释放
        {
            q = p;
            p = p->next;      // 继续扫描
            free(q);          // 释放空间
        }
    }

    r->next = NULL;           // 插入结束后尾结点指针置为 NULL
}
```

---

### 复杂度分析

两个算法都只需扫描链表一次：

- 时间复杂度：`O(n)`
- 空间复杂度：`O(1)`
