# 三指针法（Three-Pointer Technique）笔记

---

## 一、问题背景

在**单链表（Singly Linked List）**中进行结构性修改时，存在一个核心约束：

> 单向不可回溯，一旦修改 `next`，原路径可能永久丢失。

因此在进行“边重定向（pointer redirection）”操作时，必须引入保护机制。

---

## 二、三指针法的本质

### ✅ 本质定义

> 在单向不可回溯结构中，实现安全结构重构的最小完备控制系统。

三指针分别承担：

| 指针     | 作用        |
| ------ | --------- |
| `prev` | 已处理区的结构锚点 |
| `cur`  | 当前操作结点    |
| `next` | 未处理区的保护入口 |

形成三区结构：

```
[已处理区] <- prev | cur -> [未处理区]
```

---

## 三、核心操作模型

### 操作不变量

在任意时刻：

* 已处理区结构完整
* 未处理区结构完整
* 所有结点始终可达

---

### 基本迭代框架（C语言）

```c
typedef struct LNode
{
    int data;
    struct LNode *next;
} LNode;

LNode* ThreePointerModel(LNode *head)
{
    LNode *prev = NULL;
    LNode *cur = head;
    LNode *next = NULL;

    while (cur != NULL)
    {
        next = cur->next;   // 1️⃣ 保护未来
        cur->next = prev;   // 2️⃣ 重定向当前
        prev = cur;         // 3️⃣ 推进已处理区
        cur = next;         // 4️⃣ 推进未处理区
    }

    return prev;
}
```

---

## 四、操作逻辑抽象

每一轮循环完成：

$$
(A, B) \rightarrow (A', B')
$$

其中：

* $A$：已处理区
* $B$：未处理区

直到：

$$
B = \varnothing
$$

这是一个**结构分区递进重构过程**。

---

## 五、优势分析

### 1️⃣ 最小完备性

两个指针只能遍历，无法在重连时保证未来可达性。

三个指针是：

$$
\text{遍历 + 重连 + 保护未来}
$$

的最小充分条件。

---

### 2️⃣ 空间最优

* 时间复杂度：
  $$
  O(n)
  $$
* 空间复杂度：
  $$
  O(1)
  $$

原地完成结构变换。

---

### 3️⃣ 结构安全性

始终满足：

$$
\text{所有结点在任意时刻保持可达}
$$

避免断链。

---

### 4️⃣ 可泛化能力

该模型可推广至：

* [链表整体逆置](../链式表/wangdao2.3_question_3.md)
* 区间逆置
* K 组翻转
* 删除指定节点
* 去重操作
* 分段重排

本质统一为：

> 单向结构中的安全边重定向问题。

---

## 六、与双向链表的对比

| 结构类型 | 是否必须三指针          |
| ---- | ---------------- |
| 单链表  | 必须               |
| 双向链表 | 结构已内置回溯边，可减少保护压力 |

原因：

单链表是：

$$
有向无回边结构
$$

双向链表是：

$$
双向可达结构
$$

三指针本质是对“不可回溯性”的补偿机制。

---

## 七、方法级总结

一句话概括：

> 三指针法是在单向链式结构中，通过“保存未来 → 重连当前 → 滚动推进”实现安全结构重构的标准控制模型。
