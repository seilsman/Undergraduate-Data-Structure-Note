普通人对于二分查找的印象还源于高中数学课本上的“二分法确定函数零点”，在数据结构里反而是一个很重要的思想方法。
二分查找的核心思想就是：可以在递增（递减）有序表内，用`mid`与x比较，实现查询一次就将待查询范围缩小一半（当然如果x在这个表里面的话），如果`x不在数组区间内（不等于顺序表中的任何元素）`，那么直接返回false就行
前提条件：首先肯定得只能是顺序表了（顺序表/数组），因为只有顺序表具有随机存取的特性
其次查询值只能是确定的值x，且如果在数组内存在，其一定在[low,high]里

实现思路（逻辑流程）：
```C
int BinarySearch(int A[], int n, int x)//输入三个变量，依次为目标顺序表，顺序表长度（可以不用这玩意，n用L.length代替就行）
{
    int low = 0, high = n - 1, mid;//设定初始的查询范围：整个数组

    while (low <= high)//注意，只要low<=high,在算法视角就代表仍然有还未查询到的元素
    {
        mid = (low + high) / 2;//设定中间值，后续的判断条件都是基于中间值进行的

        if (A[mid] == x)//中间值等于x：直接返回值，算法结束
            return mid;
        else if (A[mid] < x)//x大于中间值的情况：排除小于中间值那一半元素，设定数组左端点为mid+1，继续用循环进行
            low = mid + 1;
        else//剩下即为x小于中间值的情况：排除大于中间值那一半元素，设定数组右端点为mid-1，继续用循环进行
            high = mid - 1;
    }

    return -1;  // low<=high的情况结束但是仍然没有返回mid值，剩下low>high的情况：代表已经没有待检查的元素与x比较，换言之，在这个数组内找不到x了
}
```
或者用递归的方法更好理解
```C
int BinarySearch(SqList &L, int low, int high, ElemType x)
{
    if (low > high)
        return -1; //代表没有可比较的元素了，直接break就行

    int mid = (low + high) / 2;

    if (x == L.data[mid])
        return mid;
    else if (x < L.data[mid])
        return BinarySearch(L, low, mid - 1, x);//进行函数递归调用，最大保证算法的可读性
    else
        return BinarySearch(L, mid + 1, high, x);
}
```

从代码的实现我们不难看出，二分查找的目的仅仅是查找x在数组中的位置，如果`low>high`的条件触发，代表数组所有数都检查完毕，没有与x匹配的元素。在之前个人手搓二分查找的代码实现过程中，我误以为这个算法还可以确定x在数组内应该push的位置。实际上，确定位置这一操作可以通过后续while循环（判断数组元素与x的关系）进行判定，这样整体写做到了更简洁的同时，也防止了当时本人写的代码中出现的“区间收缩不紧”的情况
